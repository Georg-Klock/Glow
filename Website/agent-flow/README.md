# The agent-workflow visualiser

One HTML Embed on georgklock.com/glow-up, above the "Agentically built"
item: the loop the app was built in, as cards with emoji, the GitHub mark and
arrows — Georg → Sonnet (interviews, writes the issues) → GitHub Issues →
Claude agents (build, test, merge) → tests and CI → the old iPhone tethered to
the laptop → back to Georg for the morning review.

`embed.html` is the whole thing: inline `<style>` and markup, under Webflow's
10,000-character cap, no script. It uses the page's `GW Inter` face, which the
hero's head CSS declares. On phones the row becomes a column and the arrows
point down.

Element id on the page: `61c6d399-3896-ca66-3115-2090fd04df8f` (the embed's
`code` setting). Paste the file's contents there after a change.
