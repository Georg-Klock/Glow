The machine loop minutes, around the clock, no person in it

  1. Issues, one per change.
  2. Fable reads one and plans it; Codex takes the heavy implementation when it is heavy.
  3. Gates, the Xcode suite and CI. Red sends it straight back to the agents.
  4. main, protected, auto-merge when green. Releases go on to the App Store.
  5. Debug phone, an old iPhone tethered to the laptop. Debug builds land there and its traces and screenshots go back to the agents.

Then round again, without me.

The glow is the one thing no gate can judge, because a simulator has no headroom. That question crosses to me, by eye.

The human loop twice a day, 45 minutes before and after work

  1. TestFlight puts the build on my iPhone, where I live with the app.
  2. I react to what it is actually like.
  3. Sonnet interviews me and writes the issues, which start the loop above.

Back into the machine loop.

Two loops at different speeds. The fast one closes without me. The glow is the one thing it cannot judge, so that crosses the middle and comes to my eye.
