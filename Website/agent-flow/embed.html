The build loop minutes, around the clock, no person in it

  1. GitHub is where the code lives: the issues, the pull requests, the checks and main.
  2. Fable reads an issue and plans it in the issue's comments; Codex takes the heavy implementation when it is heavy.
  3. The agents open a pull request. The gates, the Xcode suite and CI, decide: green merges to main, red goes back to the agents.
  4. Debug phone, an old iPhone tethered to the laptop. Debug builds land there and its traces go back to the agents.

Then round again, without me.

The glow is judged in the other loop, on my own phone, by eye.

The review loop twice a day, 45 minutes before and after work

  1. TestFlight puts the build on my iPhone, the only place I judge the glow.
  2. I react to what it is actually like.
  3. Sonnet interviews me, then writes both the GitHub issues and the prompts the agents run.

Back into the build loop.

Two loops. The build loop closes without me. The glow is judged only on my own phone, by eye, which is the one thing no gate can do.
