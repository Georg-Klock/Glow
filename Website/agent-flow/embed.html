The build loop minutes, around the clock, no person in it

  1. GitHub is where the code lives: the issues, the pull requests, the checks and main.
  2. Four agents work an issue, often several at once. Fable plans it in the comments, Opus writes most of the code, Codex takes the heavy implementation, Terra the long sessions where cheaper tokens matter.
  3. Two kinds of test machine: simulators on the laptop, and the debug phone, an old iPhone tethered to it. Both send results back to the agents.
  4. The agents open a pull request. The gates, the Xcode suite and CI, decide: green merges to main, red goes back to the agents.

Then round again, without me.

The glow is judged in the other loop, on my own phone, by eye.

The review loop twice a day, 45 minutes before and after work

  1. TestFlight puts the build on my iPhone, the only place I judge the glow.
  2. I react to what it is actually like.
  3. Sonnet interviews me, then writes both the GitHub issues and the prompts the agents run.

Back into the build loop.

Two loops. The build loop closes without me: four agents, two kinds of test machine, gates that merge what is green. The glow is judged only on my own phone, by eye, which is the one thing no gate can do.
