The build and test loops minutes, around the clock, no person in them

  1. An agent picks up an issue. Claude plans the change in the issue's comments and writes most of the code; Codex takes the heavy implementation and the cheaper long sessions.
  2. The work is built and run on two kinds of machine: simulators on the laptop, dozens of runs and no hardware, and the debug phone, an old iPhone tethered to it. Both send results and traces back, which is a loop of its own.
  3. The agents open a pull request. The gates, the Xcode suite and CI, run on it. Red means another commit, the second inner loop; green merges to main.

Then round again, without me.

The glow leaves the machines here, because no gate can judge it.

The feedback loop twice a day, 45 minutes — the large loop, the one I am in

  1. TestFlight puts main on my iPhone, the only place I judge the glow.
  2. I react to what it is actually like.
  3. Claude interviews me, then writes it up as GitHub issues and as the prompts the agents run.

Back into the build loop.

Two inner loops and one large one. The agents build and test in loops that close without me. The large loop closes on my own phone, by eye, which is the one thing no gate can do.
